# 第三方组件

`atlas/vendor/archify` 包含生成交互图谱所需的 Archify atlas 渲染器、运行时、样式和校验器，复用版本标识为 Archify 2.16 / local linked-atlas-1。代码按其 MIT 许可分发，完整许可见 [LICENSE](atlas/vendor/archify/LICENSE)。

`atlas/atlas-layout.mjs` 为本项目的目录布局适配；`atlas/atlas.json` 为本项目维护的图谱内容。

服务及 SDK 的其他依赖由各自的 pyproject.toml 和 package.json 声明。项目自身的发布许可尚未另行指定，第三方 MIT 许可不自动覆盖项目全部源码。
